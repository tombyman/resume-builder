# resume-builder — скил Claude Code для адаптации IT-резюме

Claude Code плагин (скил), который адаптирует ваше существующее IT-резюме под российский рынок труда (hh.ru): улучшает структуру и формулировки, генерирует версии на русском и английском в Markdown и PDF. Опционально — точечная адаптация под конкретную вакансию.

## Возможности

- Переработка резюме по стандартам российского рынка: структура, порядок блоков, измеримые результаты вместо общих фраз.
- Две версии результата: **RU** (для hh.ru) и **EN** (переработка под англоязычные conventions, а не дословный перевод).
- Каждый формат — в **Markdown** и **PDF** (PDF собирается локально через `pandoc` + `xelatex`, внешние сервисы не используются).
- Опциональная адаптация под вакансию: резюме перестраивается под ключевые слова и требования вакансии.
- Скил **не выдумывает** опыт, навыки и контакты: недостающие данные запрашиваются одним сводным списком вопросов.

## Требования

| Компонент | Зачем | Установка (Debian/Ubuntu) |
|---|---|---|
| [Claude Code](https://claude.com/claude-code) | Запуск скила | см. официальную документацию |
| `pandoc` | Сборка PDF из Markdown | `sudo apt install pandoc` |
| TeX Live (xelatex) | Движок вёрстки PDF | `sudo apt install texlive-xetex texlive-lang-cyrillic` |
| Шрифты DejaVu | Кириллица в PDF | `sudo apt install fonts-dejavu-core` |

> Если xelatex недоступен, скил соберёт PDF обходным путём: `pandoc → HTML → chromium --headless --print-to-pdf`.

## Установка

В любом проекте (или глобально) выполните в терминале:

```bash
claude plugin marketplace add https://github.com/tombyman/resume-builder
claude plugin install resume-builder@resume-builder
```

URL можно заменить на shorthand `owner/repo`:

```bash
claude plugin marketplace add tombyman/resume-builder
claude plugin install resume-builder@resume-builder
```

После установки скил доступен в сессии Claude Code как `/resume-builder`.

## Использование

1. Подготовьте исходное резюме: файл (`.md`, `.txt` или `.pdf`) либо текст прямо в сообщении.
2. Запустите скил:

   ```
   /resume-builder путь/к/резюме.md
   ```

   — или просто попросите своими словами: «адаптируй моё резюме под hh.ru», приложив файл или встав текст.
3. Если хотите адаптацию под вакансию — добавьте текст вакансии или её требования.
4. Скил задаст один сводный список вопросов по недостающим данным (контакты, даты, образование, зарплатные ожидания). Ответьте — и получите результат.

### Результат

В текущей директории появятся файлы:

```
ГГГГ-ММ-ДД Фамилия Имя - резюме ru.md   # RU-версия, Markdown
ГГГГ-ММ-ДД Фамилия Имя - резюме ru.pdf  # RU-версия, PDF
ГГГГ-ММ-ДД Lastname Firstname - resume en.md  # EN-версия, Markdown
ГГГГ-ММ-ДД Lastname Firstname - resume en.pdf # EN-версия, PDF
```

После генерации скил покажет краткий список изменений и спросит, что доработать — правки вносятся итеративно.

## Принципы работы

- **Только факты из вашего резюме.** Ничего не выдумывается: опыт, навыки и контакты берутся из исходных данных или ваших ответов на вопросы.
- **Прозрачность сокращений.** Из исходного резюме ничего не удаляется без причины — при сокращении скил объясняет, что вырезано и почему.
- **Локальная обработка.** PDF собирается на вашей машине; резюме никуда не отправляется.

## Для разработчиков

Репозиторий одновременно является плагином и marketplace (корень репозитория = корень плагина):

```
.claude-plugin/plugin.json        # манифест плагина
.claude-plugin/marketplace.json   # манифест marketplace
skills/resume-builder/SKILL.md    # входная точка скила
skills/resume-builder/references/ # справочные материалы (стандарты рынка РФ)
skills/resume-builder/templates/  # LaTeX-шаблон вёрстки PDF
```

Локальная проверка без публикации:

```bash
claude plugin validate .
claude --plugin-dir .
```

Подробности о структуре и правилах разработки — в [CLAUDE.md](CLAUDE.md).
